A robot deployed over a long lifetime must learn new tasks continuously while retaining
old ones. This is the continual learning problem — neural networks tend to catastrophically
forget earlier tasks when fine-tuned on new data.

### Key topics

- Catastrophic forgetting in neural networks
- Elastic Weight Consolidation (EWC) and other regularization approaches
- Progressive neural networks: no forgetting by architecture expansion
- Experience replay and generative replay
- Connections to autonomous learning (Lecture 20)
