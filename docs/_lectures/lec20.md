The long-term vision is a robot that learns continuously from its own experience.
This lecture examines what that requires: automated reset mechanisms, curriculum learning,
self-supervised data collection, and the integration of model-based planning with exploration.

### Key topics

- Autonomous reset and robot self-supervision
- Automatic curriculum learning (ACRL, ALP-GMM)
- Self-supervised and intrinsically motivated data collection
- Integrating model-based planning with autonomous exploration
- Connections to lifelong learning (Lecture 19) and unsupervised RL (Lecture 15)
