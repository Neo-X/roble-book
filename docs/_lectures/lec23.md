Deep RL is notoriously finicky. This lecture distills practical advice for getting algorithms
to work in practice — from sanity checks and debugging strategies to principled algorithm
selection and the most common sources of silent failure.

### Key topics

- Algorithm selection guide: when to use which method
- Hyperparameter sensitivity and tuning strategies
- Debugging: reward curves, rollout visualization, gradient norms
- Common failure modes and how to detect them early
- Reproducibility and evaluation best practices
